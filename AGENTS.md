# AGENTS.md

Read [CLAUDE.md](CLAUDE.md) first, then obey it. It holds the rules for this
repository. If this document and CLAUDE.md do not agree, CLAUDE.md is correct.

This repository holds the public website of the Tyrrell Lab at the UAB Heersink
School of Medicine. It has seven static HTML pages. There is no build step, no
package manager and no framework. Start the server with
`python3 -m http.server 4173`, then open <http://localhost:4173/index.html>.
See [SERVER.md](SERVER.md).

The other documents are [DESIGN.md](DESIGN.md) for colour, type, layout and
movement, [PRODUCT.md](PRODUCT.md) for the words on a page and the persons that
they speak to, and [CREDITS.md](CREDITS.md) for the licences.

All these documents use ASD-STE100 Simplified Technical English. Use the same
English, and keep each document short.
