# Notices for other persons' work

This site is a static build with no package manager, thus this document holds
the notices that the licences make necessary. Three components have legal
conditions.

## The hero: ThreeUI

The files `assets/css/hero.css`, `assets/js/hero-liquid.js` and
`assets/js/hero-scene.js` come from the ThreeUI `SylvaHero` component (the
Living Green variant), source file
`public/landing-pages/inner-green-3d.html` in
<https://github.com/MengTo/threeui>. The lab changed the scene from a mossy
root into branching microvasculature and wrote much of the code again. But
sufficient structure, layout and movement of the source remain, thus the site
uses a large part of the source:

> Copyright (c) 2026 Meng To

The licence is MIT. The rendered page does not have to show a credit.

## The webfont: Lexend

The file `assets/vendor/lexend-latin.woff2` is a Latin subset of Lexend.

> Copyright 2018 The Lexend Project Authors
> (https://github.com/googlefonts/lexend), with Reserved Font Name
> "RevReading Lexend".

The licence is the SIL Open Font License 1.1. That licence makes this notice
and the full licence text necessary wherever a person supplies the font file.
The site sends the font to each visitor, thus the full text stays adjacent to
the font in [assets/vendor/lexend-OFL.txt](assets/vendor/lexend-OFL.txt). Keep
the two files together. The family name in the CSS is `Lexend`, not the
reserved name, thus clause 3 permits the subset.
